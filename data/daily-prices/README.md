# 日本株の日次株価

JPX「東証上場銘柄一覧」の現行内国株式を母集団とし、Yahoo Financeの非公式
chart endpointから取得した候補探索用の日足である。GitHub Actionsが平日18:30
（Asia/Tokyo）に直近7暦日を再取得し、変更がある場合だけPRを作成する。

## 列

- `日付`
- `銘柄コード`
- `銘柄名`
- `市場・商品区分`
- `33業種区分`
- `始値`
- `高値`
- `安値`
- `終値`
- `前日比`: 同じYahoo時系列における直前取引日の終値との差
- `前日比％`: `前日比 / 直前取引日の終値 * 100`
- `売買高(株)`
- `取得状態`: `OK`、`NO_QUOTE`、または`FETCH_ERROR`

日付別CSVは`YYYY/YYYY-MM-DD.csv`、最新の取得カバレッジは`latest.json`に保存する。
現在の上場銘柄を母集団にするため、過去日に上場廃止済みだった銘柄は含まれず、
新規上場前の期間は`NO_QUOTE`になる。

## 注意

Yahoo Financeのchart endpointは公式APIではなく、仕様・アクセス制限・提供継続は
保証されない。大量アクセスを抑えるため同時実行数を4に制限し、query1/query2の
フォールバックと再試行を行う。このデータだけで売買判断や注文票を作らず、
12週間経過後に利用可能になるJ-Quants等の公式データで再照合する。

データを公開リポジトリへ保存するときは、利用者自身がYahooおよび元データ提供者の
最新の利用条件に照らして公開・保存方法を確認すること。
